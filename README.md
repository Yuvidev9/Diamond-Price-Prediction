# Diamond Price Prediction Using KNN

## Project Overview
This project predicts the estimated price of a diamond using a K-Nearest Neighbors (KNN) regression model. A Streamlit web application allows users to enter diamond characteristics and receive a price prediction.

## Features
- Interactive Streamlit interface
- KNN regression model
- Numerical and categorical feature preprocessing
- Diamond price prediction from user inputs

## Technologies Used
- Python
- Pandas and NumPy
- Scikit-learn
- Streamlit
- Pickle

## Project Structure
- `app.py` — Streamlit application
- `data/diamonds.csv` — Dataset
- `models/knn_diamond_model.pkl` — Trained model pipeline
- `notebooks/` — Data exploration and model training

## Run Locally
Install the dependencies:

```bash
pip install -r requirements.txt
```

Run the application:

```bash
python -m streamlit run app.py
```

## Note
Predicted prices are estimates generated by a machine-learning model and are not guaranteed market prices.
